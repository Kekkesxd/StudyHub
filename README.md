# StudyHub

StudyHub is an ASP.NET Core MVC student planner web application.

## Features

- User registration and login
- Session-based authentication
- Course management
- Current Courses feature
- Assignment management
- Dashboard statistics
- Profile page
- SQLite database
- Dark responsive UI

## Live Demo

https://studyhub-7y0p.onrender.com

## Technologies

- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQLite
- Razor Views
- Bootstrap
- CSS
- Docker
- Render
